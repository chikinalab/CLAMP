# xCell cell-signature matrix

A numeric matrix of cell-type signatures derived from xCell, used to
represent the transcriptional profiles of distinct immune and stromal
cell populations.

## Usage

``` r
data(xCell)
```

## Format

A numeric matrix with G genes (rows) and C cell types (columns). Row
names are gene symbols; column names are xCell cell-type labels.

## Value

A matrix of xCell-derived reference expression signatures.

## Examples

``` r
data(xCell)
```
